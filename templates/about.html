About This Project


Project Overview

Fake News Detection Using Machine Learning and Natural Language Processing (NLP) is a web-based application that predicts whether a news article is Real or Fake. The system analyzes the text entered by the user using a trained Machine Learning model.


Objectives

  • Detect fake news using Machine Learning.
  • Reduce the spread of misinformation.
  • Provide prediction confidence.
  • Maintain prediction history.
  • Provide a simple and user-friendly interface.

Technologies Used

Technology Purpose
Python Backend Programming
Flask Web Framework
Scikit-Learn Machine Learning Model
NLTK Text Preprocessing
HTML User Interface
CSS Styling

System Workflow

  1. User enters a news article.
  2. Text is cleaned using NLP techniques.
  3. TF-IDF converts text into numerical vectors.
  4. Machine Learning model predicts the result.
  5. Confidence score is displayed.
  6. Prediction is stored in history.

Key Features
